# Release Readiness

## Evidence categories

### Functional
- Critical-path regression complete
- Changed-area regression complete
- Exploratory charters complete

### Defects
- No unresolved Critical defects unless explicitly accepted
- High defects reviewed with impact and mitigation

### Non-functional
- Required performance checks within threshold
- Relevant security controls verified
- Accessibility/compatibility checks complete when in scope

### Operational
- Monitoring/logging available
- Rollback or recovery plan understood
- Feature flags/configuration verified

## Decision record

A release recommendation should state:

- build/version
- evidence reviewed
- unresolved risks
- mitigation/workarounds
- decision owner
- follow-up actions

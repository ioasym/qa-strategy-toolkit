# Severity vs Priority

**Severity** describes impact. **Priority** describes how urgently the team chooses to address it.

| Example | Severity | Possible priority |
|---|---|---|
| Duplicate charge | Critical | Immediate |
| Checkout blocked for all users | Critical | Immediate |
| Broken admin page rarely used | High | Depends on release scope |
| Typo on campaign landing page | Low | Could be high before campaign launch |

Avoid deriving priority mechanically from severity; release timing, exposure, workaround, and contractual obligations matter.

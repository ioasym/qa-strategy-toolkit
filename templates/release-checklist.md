# Release Readiness Checklist

## Build and environment
- [ ] Release candidate uniquely identified
- [ ] Environment configuration verified
- [ ] Feature flags verified

## Functional quality
- [ ] Critical-path regression passes
- [ ] Changed-area tests complete
- [ ] Required exploratory charters complete

## Defects and risk
- [ ] No unexplained Critical defects
- [ ] High defects reviewed
- [ ] Residual risks documented

## Non-functional
- [ ] Required performance evidence available
- [ ] Required security evidence available
- [ ] Compatibility/accessibility obligations checked

## Operations
- [ ] Monitoring/alerts ready
- [ ] Rollback/recovery path understood
- [ ] Known limitations communicated

## Evidence
- [ ] Results and artifacts linked
- [ ] Decision owner recorded

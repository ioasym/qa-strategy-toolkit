# Risk Register Template

Use one row per material business/product failure mode. Record the rationale so a reviewer can understand **why** the score was chosen.

| ID | Capability | Failure mode | Impact (1–5) | Impact rationale | Likelihood (1–5) | Likelihood rationale | Score | Band | Primary treatment | Release treatment | Owner | Status |
|---|---|---|---:|---|---:|---|---:|---|---|---|---|---|
| RISK-001 | CAP-xx |  |  |  |  |  |  |  |  |  |  | Open |

## Scoring rule

```text
Risk score = Impact × Likelihood
```

Use the definitions in `risk/risk-assessment-model.md` rather than choosing numbers intuitively.

## Optional override record

If the default treatment is escalated or reduced, record:

- baseline score/band
- treatment override
- rationale
- accountable owner
- review/expiry condition

Prefer a transparent treatment override over manipulating the numeric score to force a desired band.
